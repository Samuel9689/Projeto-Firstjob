# 💼 First Job

**Conectando talentos às oportunidades!**

## 📌 Sobre o projeto

O **First Job** é um projeto de desenvolvimento web criado com o objetivo de ajudar jovens que estão em busca do primeiro emprego a conhecer oportunidades profissionais e iniciar sua trajetória no mercado de trabalho.

A plataforma apresenta vagas de emprego, áreas profissionais e informações sobre oportunidades, oferecendo uma interface simples e intuitiva para os usuários.

## 🎯 Objetivo

Desenvolver um site que facilite a busca pelo primeiro emprego, permitindo que os usuários conheçam diferentes áreas profissionais e visualizem oportunidades disponíveis.

## 🚀 Funcionalidades

- **Login:** página de acesso à plataforma.
- **Cadastro:** formulário para criação de conta.
- **Recuperação de senha:** página para solicitação de recuperação de acesso.
- **Página inicial:** apresentação do projeto e dicas para conquistar o primeiro emprego.
- **Vagas:** listagem de oportunidades profissionais.
- **Áreas profissionais:** apresentação de diferentes setores do mercado de trabalho.
- **Detalhes da oportunidade:** informações sobre empresa, modalidade, experiência exigida e descrição da vaga.

## 🛠️ Tecnologias utilizadas

- HTML5 — Estruturação das páginas.
- CSS3 — Estilização e organização visual.
- Git — Controle de versão.
- GitHub — Hospedagem do código-fonte.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Entre na pasta `html`.
4. Abra o arquivo `index.html` em seu navegador.
5. Navegue pelas páginas utilizando os menus e links disponíveis.
